# Instagram-Clone

A simple Instagram-inspired web application built with React and Vite.

## Features

- Instagram-style user interface
- Stories section
- Posts feed
- User profile section
- Suggestions sidebar

## Technologies Used

- React.js
- Vite
- JavaScript
- HTML and CSS
- Bootstrap
- JSON Server for local API data

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/mohanakannandev/Instagram-Clone.git
```

### 2. Navigate to the project folder

```bash
cd Instagram-Clone
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the JSON Server

```bash
npx json-server db/db.json --port 3000
```

Keep this terminal running.

### 5. Start the React application

Open another terminal and run:

```bash
npm run dev
```

Open the local URL displayed in the terminal.
